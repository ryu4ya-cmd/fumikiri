# ふみきり カンカン

幼児向けの、電車と踏切のあそびです。ブラウザで開くだけで遊べます。

iPhone・iPad の Safari で開いて「共有 → ホーム画面に追加」をすると、アプリのように全画面で遊べます。

電車は、阪急電車をイメージした色（マルーンの車体、アイボリーの屋根のふち、銀色の窓わく）で描いています。

## あそびかた

ホームで、あそびかたを選びます。

- **ふみきり**：踏切（または景色のどこか）をさわると、警報機がカンカン鳴って、赤いランプが交互に光り、遮断機がおります。方向指示器（← →）が、電車の来る向きを教えてくれます。左へ行く電車は手前の線路、右へ行く電車は奥の線路を走ります。ときどき、両方から来て すれちがったり、あとから もう1本 来たりします。走っている電車をさわると、警笛を鳴らして お客さんが手をふります。道の くるまは、踏切がしまっている間は停止線で待ちます。
- **しゅっぱつ！**：駅「どうぶつえんまえ」のホームで電車を待ちます。「まもなく、とっきゅうが まいります」のアナウンスのあと、電車がだんだん ゆっくりになって止まります。電車をさわるとドアが開いて、「おりる おきゃくさんが さきだよ」と どうぶつが降ります。ホームで待っている どうぶつを さわると乗ります（ホームのどこをさわっても、待っている どうぶつが順に乗ります）。みんな乗ったらドアを閉めて、「しゅっぱつ」ボタンで発車ベルと車掌さんの笛が鳴り、「しゅっぱつ しんこう！」で出発します。ときどき、奥の線路を とっきゅうが通過します。
- **なんりょう？**：通る電車の車両に、1、2、3…と数字が出ます。通りすぎたら「なんりょう だった？」と聞かれるので、こたえを選びます。5問で おしまいです。
- **でんしゃずかん**：「ふみきり」と「しゅっぱつ！」で会った電車が集まります（ふつう・きゅうこう・とっきゅう・ながーい でんしゃ・はなの でんしゃ・どうぶつ でんしゃ・おばけ でんしゃ の7しゅるい）。まだ会っていない電車は、かげになっています。

正解すると、大きな はなまる とファンファーレでお祝いします。まちがえても失敗にはなりません。正解のボタンが光って教えてくれます。

## 声について

ゲームの声は、Style-Bert-VITS2 モデル「小春音アミ」で前もって作った声（`voice/`）を使っています。
このモデルは、[あみたろの声素材工房](https://amitaro.net/) の声をもとにしたものです（モデルの作者：litagin さん。[利用規約](https://huggingface.co/litagin/sbv2_koharune_ami)）。
声のファイルがない場所（claude.ai の公開ページなど）では、端末の読み上げ機能を使います。

声は、1つのセリフにつき何とおりか作り、音声認識（faster-whisper）で聞きとって、セリフどおりに いちばん はっきり聞こえたものを選んでいます（`tools/make_voice.py --pick 6`）。数や「〜両」のように聞きとりにくいことばは、漢字まじりの文で読ませています。

効果音（踏切の「カーン」、警笛、線路のつなぎめの「ガタン」、ブレーキの「ぷしゅー」「キーッ」、ドアとチャイム、発車ベル、車掌さんの笛、くるまのクラクション、遮断機）は、`tools/make_sounds.py` で数式から作った音のファイル（`sounds/`）です。走っている間の「ごー」とモーターの「ういーん」、BGM は、ブラウザの中で その場で作っています（速さに合わせて音の高さや大きさが変わります）。

## 保護者の方へ

- 右下の ⚙️ を長押しすると、保護者メニューが開きます。ゲームの声と端末の読み上げの切りかえ、読み上げの声の種類・高さ・速さ、BGMの音量、ふみきりの音の大きさ、ずかんのリセットができます。
- ホーム右上の 🎵 で BGM を消せます。
- ずかん（会った電車の記録）は、その端末のブラウザの中だけに保存されます。

## 古いタブレットで遊ぶとき

もじもじの もり と同じく、古いブラウザでも動くようにしています（目安は Chrome 49 以降）。

- 端末に新しい絵文字がなくて□になるときは、ゲームについている絵文字フォント（`fonts/emoji.ttf`）に自動で切りかわります。
- うまく動かないときは画面の上に案内が出ます。保護者メニューの下のほうに、使っているブラウザのバージョンが出ます。

## ファイル

- `src/game.html`：ゲーム本体。直すときはこのファイルを編集します（claude.ai の公開ページもこのファイル）。
- `tools/build.js`：`src/game.html` から `index.html` を作ります。古いブラウザでも動くように、スクリプトの書き方を Babel で変換します。
  はじめの1回だけ `npm install`、そのあとは直すたびに `npm run build`。
- `index.html`：公開用のページ（自動で作られるので、直接は編集しません）。
- `icons/`、`manifest.webmanifest`：ホーム画面に追加したときのアイコンと設定。アイコンの元の絵は `icons/icon.svg`、png は `tools/make_icons.js`（Playwright を使います）で作ります。
- `sounds/`：効果音（`tools/make_sounds.py` で作る）。
- `voice/`：ゲームの声（mp3 と、セリフの部品 → ファイル名の表 `index.json`）。セリフを足したら `tools/make_voice.py` で足りない分を作ります（作り方はスクリプトの先頭に書いてあります）。
- `tools/voice_lines.js`：ゲームで使う声の部品をぜんぶ出します（`tools/make_voice.py` が使います）。
- `fonts/`：古い端末向けの絵文字フォント（Noto Color Emoji から使う絵文字だけを抜き出したもの。ライセンスは `fonts/OFL.txt`）。絵文字を足したら `tools/make_emoji_font.py` で作り直します。
